# 제품 요구 사항

English: [PRD.md](PRD.md)

Android 기기(폰·태블릿)와 Mac 사이에서 파일을 보고 옮기는 macOS 앱 **SolidFerry**("Fast, robust, native Android file transfer for Mac").

## 문제

- macOS는 Android 기기를 Finder에 보여 주지 않는다. 이미지 캡처·사진 앱은 사진만 가져온다.
- 기기 안 폴더 구조를 보며 원하는 파일만 옮기거나 기기에서 정리하려면 따로 도구가 필요하다.
- 사진 폴더처럼 파일이 수천~수만 개인 폴더, GB 단위 동영상에서 느리거나 중간에 끊기고, 끊긴 뒤 무엇이 옮겨졌는지 알기 어렵다.
- 같은 이름의 파일이 이미 있을 때 덮어쓸지 건너뛸지를 파일 단위로 다루기 어렵다.
- 기존 앱들은 이 중 일부씩을 해결하고 있고, 그 앱들이 잘하는 부분은 이 앱의 기본선이다.
  - **Android File Transfer**(Google)는 공식 도구였다. 지금은 단종됐고, 큰 폴더에서 수십 초씩 멈추곤 했다.
  - **[OpenMTP](https://github.com/ganeshrvel/openmtp)**는 Android File Transfer와 함께 널리 쓰여 온 무료 오픈소스 프로젝트(Electron)다. MTP로 동작한다. 파일이 수천 개인 폴더는 목록이 뜨기까지 시간이 걸리고, Shift-클릭 범위 선택은 지원하지 않는다.
  - **MacDroid**는 기기를 Finder에 보여 주고 MTP와 ADB 모드를 모두 지원한다. Mac에서 기기로 복사하는 기능은 유료 Pro 버전에 있다.
- 비어 있는 자리는 MTP와 ADB를 모두 쓰고, 아주 큰 폴더에서도 빠르며, 큰 파일을 내려받지 않고 기기에서 바로 여는 무료 네이티브 앱이다.

## 사용자

- Android 기기를 쓰는 Mac 사용자. 개발자 옵션을 켜지 않은 사람(MTP)과 USB 디버깅을 켜는 사람(ADB) 모두.
- 사진·동영상을 Mac으로 백업하거나, Mac의 파일을 기기로 보내거나, 두 기기 사이에서 옮기는 사람.

## 핵심 기능

| 영역 | 내용 |
|---|---|
| 연결 | USB로 꽂으면 바로 보임. USB 디버깅이 켜져 있으면 ADB, 아니면 MTP를 자동으로 고름(직접 고를 수도 있음). Wi-Fi(무선 디버깅)로도 연결: QR 코드나 페어링 코드로 한 번 페어링하면 그다음부터 자동으로 연결 |
| 연결 문제 | 연결이 안 되는 실제 원인을 찾아 할 일 하나를 보여 줌(충전 전용 모드, 다른 앱이 잡고 있음, 기기의 허용 대기 등). 안전한 조치는 앱이 직접 함 |
| 탐색 | Finder 같은 목록(이름·크기·날짜·종류, 정렬), 경로 막대, 사이드바(기기마다 자주 쓰는 폴더, SD 카드나 USB 드라이브, 오른쪽 클릭 ▸ 사이드바에 추가로 넣은 폴더), 탭과 여러 창, 숨김 파일 보기. ⌘F로 입력하는 대로 이름을 검색(정규식도 가능, 기기에 다시 묻지 않음). 스페이스로 선택한 파일을 보기 창에 보여 주고 다시 누르면 닫음(훑어보기). 웹 브라우저처럼 ⌫는 뒤로, ⇧⌫는 앞으로 |
| 옮기기 | Mac→기기, 기기→Mac, 기기→기기. 드래그 앤 드롭, 복사·붙여넣기, 메뉴 어느 쪽으로 해도 같은 전송 대기열의 작업 하나 |
| 이미 있는 파일 | 건너뛰기·덮어쓰기·둘 다 유지·크기나 날짜가 다를 때만·내용이 다를 때만(모든 파일을 먼저 비교한 뒤 보냄), 그리고 파일별로 묻기. 받을 때는 날짜만 다른 파일의 날짜만 맞출 수 있음. 미리보기로 무엇이 어떻게 될지 시작 전에 확인하고, 다시 읽을 수 있음(새로고침). 이 창은 따로 떠서 옮기고 크기를 바꿀 수 있음(목록을 넓게) |
| 전송 대기열 | 기기마다 구역 하나: 기기마다 작업을 하나씩 차례로, 기기끼리는 동시에. 진행률과 속도(몇 초 평균), 아무것도 오가지 않을 때는 무엇을 기다리는지(기기, Mac의 디스크). 작업별 일시정지·재개·취소, 멈출 때까지 "일시정지하는 중…". 실패한 파일 목록과 다시 시도. 앱을 다시 열어도 이어서 진행. 연결이 끊기면 기다렸다가 다시 연결되면 이어서 |
| 전송 결과 | 작업을 더블클릭: 원본·대상 위치, 옵션, 시간과 평균 속도, 파일마다 원래 있던 것·들어온 것·한 일(복사, 건너뜀과 이유, 덮어씀, 둘 다 유지와 새 이름, 날짜만 맞춤, 실패와 이유)·끝난 뒤 있는 것, 내용을 비교했으면 해시. 전송 창에서 지울 때까지 남음 |
| 날짜 유지 | 받은 파일의 날짜를 바꾸는 기기로 보낼 때 ZIP 하나로 묶어 보내고, 기기에서 풀면 원래 날짜가 남음 |
| 미리보기와 보기 | 목록 옆 미리보기 패널(사진, 동영상 프레임과 길이·해상도, 텍스트, PDF 첫 쪽, 음악 표지, 모든 파일 정보). 사진·동영상·음악을 기기에서 바로 읽어 보여 주는 보기 창: 몇 GB짜리 동영상도 먼저 받지 않고 바로 열고 원하는 위치로 이동한다. 다른 앱으로 열기 |
| 기기에서 정리 | 새 폴더, 이름 바꾸기, 여러 파일 이름 한 번에 바꾸기(찾아 바꾸기·번호·대소문자), 삭제 |
| 설정 | 화면 부분별 글자 크기, 툴바 모양, Wi-Fi 자동 연결, 사진 서비스가 기기를 먼저 잡지 않게 하기 |
| 언어 | 영어, 한국어 |

## 품질 기준

- **기존 파일을 잃지 않는다.** 기본은 이미 있는 파일을 건드리지 않는 쪽. 덮어쓰기는 새 파일을 다 받은 뒤에 바꾼다. 중간에 끊겨도 원본이 반쯤 쓴 파일로 바뀌지 않는다.
- **빠르다.** 목록은 첫 부분이 오면 바로 그린다. 전송 속도는 연결 한계(USB 2·3, Wi-Fi)에 가깝게 낸다. 작은 파일이 많을 때도 빠르다.
- **기기를 멈추게 하지 않는다.** 기기를 멈출 수 있는 방식은 시험하지 않고 피한다.
- **문구는 결과와 할 일만.** 내부 동작은 보여 주지 않는다.
- **설치가 쉽다.** ADB가 없으면 앱이 안내하고 받아 준다(Google 배포본 또는 Homebrew). ADB 없이도 MTP로 쓸 수 있다.

## 하지 않는 것

- 목록에서 썸네일·미디어 정보 보여 주기(목록 속도를 위해)
- 기기 쪽 앱 설치(기기에는 아무것도 깔지 않는다)
- iPhone, Windows, 클라우드 저장소

## 배포

- 오픈 소스(MIT). GitHub에서 DMG로 배포하며 Mac App Store 밖에서 배포(adb 서버 소켓과 USB에 직접 접근하려면 샌드박스를 끌 수밖에 없음)
- 최소 macOS 14

## 정할 것

- 양방향 자동 동기화(폴더 맞추기)를 할지
- 공식적으로 지원할 가장 낮은 Android 버전
